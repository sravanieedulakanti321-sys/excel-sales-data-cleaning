# Data Analyst Internship – Task 1
## Data Cleaning and Preprocessing

### Dataset
Sales Data (`sales_data.csv`)

### Objective
Clean and prepare the raw sales dataset for analysis.

### Tools
Excel.

### Files
- `sales_data.csv` – original dataset
- `cleaned_sales_data.csv` – cleaned dataset
- `data_cleaning.py` – preprocessing code
- `cleaning_summary.txt` – summary of changes

### Cleaning Steps
- Standardized column names.
- Removed leading/trailing whitespace from text values.
- Converted `sale_date` to datetime.
- Checked and removed exact duplicate rows.
- Checked missing values.
- Checked categorical consistency.
- Validated the region/sales-representative composite field.

### Result
The dataset contained no missing values and no exact duplicate rows before cleaning. The main changes were format standardization and date conversion. The cleaned dataset is ready for further analysis or visualization.
